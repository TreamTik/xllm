## 最小复现

在匹配平台按官方指引安装 PyTorch、torch_npu、triton-ascend；依赖版本见 requirements.txt。解压原题附件作为 `<task-package>`，其中包含 case.json、generate_data.py、golden.py 和任务书。独立工程 ZIP 已附完整 task-spec。

```bash
source /usr/local/Ascend/cann-9.1.0/set_env.sh
source <venv>/bin/activate
export ASCEND_RT_VISIBLE_DEVICES=0 OMP_NUM_THREADS=1 MAX_JOBS=2
export TRITON_CACHE_DIR=<independent-cache>
cd <xllm-checkout>
export PYTHONPATH="$PWD"
python -m pytest --noconftest tests/python/test_token_offset_tile_flags.py -q --junitxml=<results>/pytest.xml
python examples/kernels/token_offset_tile_flags/verify.py --task-package <task-package> --output-dir <results>
```

首次非空 prepare 仅 JIT 编译本 Triton 核。不构建服务器、C++ 扩展或 ACLNN 包；编译缓存和结果均放源码目录之外。独立工程在解压目录运行：

```bash
export PYTHONPATH="$PWD"
python -m pytest tests/test_token_offset_tile_flags.py -q
python verify.py --task-package task-spec --output-dir <results>
python verify.py --task-package task-spec --output-dir <engineering-results> --mode engineering
```

## 检查内容和本轮结果

精度使用原题冻结 CPU 标杆逐 UINT8 元素精确比较，无容差。原题 14/14 正向、9/9 非法输入、2/2 当前值更新和存储重绑定检查通过。正式 pytest 35/35，通过 11 组 INT32 上界 offset 对齐和 14 组高位精确除法回归，seed=19。输入保持、输出形状/类型/设备/连续性/独立存储均检查。

大小性能输入均检查候选与冻结基线：两条 stream 各保留 3 输出，每份对标杆；输出 storage 两两独立。预热后测单次峰值增量。20 次调用每次检查内容、释放输出并同步，逐次活跃内存均回到调用前。逐份、逐次记录在内存日志。独立工程入口补充复验单列，不拼入性能轮次。

性能按原题测完整 prepared.run 的主机 wall time，包含新输出和最终同步。prepare 的一次校验与 JIT 编译排除。候选及基线各预热 50 次；6 轮交替执行顺序；每轮 200 调用，以该轮总时间除以 200 得 us。用六轮配对均值差作共同 bootstrap：10000 次、seed=20261031、linear 分位数。主两组同时核对均值、中位数、收益区间下界>0及候选均值<=85 us。T255、257仅报告，无85us或收益硬门槛。
