## 环境与依赖

本轮为 aarch64、Python 3.12.13、PyTorch 2.7.1+cpu、torch_npu 2.7.1.post8、
triton-ascend 3.6.0.post2（Triton runtime 3.6.0）、NumPy 2.5.4、Ninja 1.13.2、pytest 8.4.2。
CANN 显式加载 `/usr/local/Ascend/cann-9.1.0/set_env.sh`。
实际 AscendCL 库为 `/usr/local/Ascend/cann-9.1.0/aarch64-linux/lib64/libascendcl.so`。
JIT 使用 C++17 编译器。无需构建整个 xLLM server，也无需自定义 ACLNN 安装包或模型权重。

新环境需先按官方安装说明准备与机器架构、Python、CANN 9.1.0 匹配的 wheel。
以下命令中 `<wheelhouse>` 是这组匹配 wheel 所在目录。不要用其他架构的包覆盖现有工作环境。

```bash
python3.12 -m venv <venv>
source <venv>/bin/activate
python -m pip install --no-index --find-links <wheelhouse> \
  'torch==2.7.1+cpu' 'torch_npu==2.7.1.post8' 'triton-ascend==3.6.0.post2' \
  'numpy==2.5.4' 'ninja==1.13.2' 'pytest==8.4.2'
```

已配置好的机器直接复用匹配环境。本次环境存在历史依赖元数据冲突；没有把 pip check 标记为通过。
实际 NPU、Triton 编译及以下完整验证均已成功。

## 构建和完整运行

解压完整工程。设置分配的物理设备可见性，程序使用逻辑设备 0。
结果、构建与 Triton 缓存目录放在工程外。每次运行使用新的结果目录。

```bash
cd <unpacked-project>
source /usr/local/Ascend/cann-9.1.0/set_env.sh
source <venv>/bin/activate
export ASCEND_RT_VISIBLE_DEVICES=<assigned-device>
export PYTHONPATH="$PWD/source"
export OMP_NUM_THREADS=1 MAX_JOBS=2 PYTHONDONTWRITEBYTECODE=1
export TORCH_EXTENSIONS_DIR=<absolute-build-directory>
export TRITON_CACHE_DIR=<absolute-triton-cache-directory>
mkdir -p "$TORCH_EXTENSIONS_DIR" "$TRITON_CACHE_DIR"
tmux new-session -d -s packed-validation \
  "bash '$PWD/run_validation.sh' '<absolute-new-results-directory>' > '<absolute-launch-log>' 2>&1"
```

第一次非空 prepare 自动 JIT 构建 C++ 扩展并编译所需 Triton 核。
构建、prepare、输入传输和 CPU 标杆检查均在计时范围外。
脚本使用 `set -euo pipefail`；功能、pytest、性能或结果复核任一失败即非零退出。

各阶段也可单独运行：

```bash
python task-spec/golden.py --verify-functional --implementation "$PWD" \
  --output <results>/functional.json
python -m pytest --noconftest source/tests/python/test_packed_page_indices.py -q
python benchmark.py --output <results>/performance.json
python verify_results.py <results>
```

`--noconftest` 用于绕开 server 专用 conftest 初始化。此算子测试不依赖 server fixtures。
输入构造及种子见 `task-spec/case.json` 和 `generate_data.py`。
性能按两侧各 50 次预热、6 轮交替、每轮 200 次执行。
计时包含完整 prepared.run、新输出及临时分配、Python 提交和轮末 NPU 同步。
配对 bootstrap 共同重采样 10000 次，seed=20261031，分位数使用线性插值。
